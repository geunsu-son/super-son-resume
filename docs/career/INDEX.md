# 이력 참고 자료 인덱스

웹 이력서(`site/`) 수정·어필 포인트 정리 시 **사실 근거**로 참고하는 원천 문서입니다.  
에이전트는 이력 문구를 바꾸기 전에 이 폴더를 우선 확인합니다. 없는 성과·수치는 추가하지 않습니다.

| 파일 | 조직·기간 | 용도 |
|---|---|---|
| `리팅랩스_데이터_엔지니어_경력기술서_초안.md` | 리팅랩스 · 데이터 엔지니어 | 이종 데이터 결합, ETL·파이프라인, 대시보드·보고 등 경력기술 초안 |
| `퍼플아카데미_복귀후_업무정리_202604-202608.md` | 퍼플아카데미 · 2026.04–2026.08 | 복귀 후 업무·성과 정리 (최근 구간) |
| `퍼플아카데미.pdf` | 퍼플아카데미 | 퍼플아카데미 관련 이력 PDF 원본 |

## 사용 규칙

1. `site/index.html` 등 공개 문구는 이 문서에 **확인된 사실**만 반영한다.
2. 문서 간 표현이 다르면, 공개 사이트에는 더 보수적·검증 가능한 쪽을 택한다.
3. 이 폴더는 참고용이다. 사이트에 원문을 그대로 붙여 넣지 않는다.
4. 민감 정보(내부 URL, 미공개 수치, 개인 연락처 등)는 공개 페이지에 옮기기 전에 사용자 확인을 받는다.
