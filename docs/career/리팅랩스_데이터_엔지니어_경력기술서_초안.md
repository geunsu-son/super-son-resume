### Data Engineer

**멀티소스 데이터 통합 파이프라인 설계 및 구축**
- SCRM, MetaCRM, DentWeb, TCM 등 서로 다른 운영 시스템과 PostgreSQL·MySQL·MSSQL 데이터를 통합하는 End-to-End 데이터 파이프라인 설계 및 구축
- 병원 및 지점별 상이한 데이터 구조와 비즈니스 규칙을 표준화하여 통합 예약·통합 수납 데이터 모델 구축
- 원천 데이터 수집부터 정제·결합·DB 적재·데이터마트·리포팅까지 전체 데이터 라이프사이클 자동화
- SQLAlchemy 기반 DB connection layer를 공통화하고 retry, connection validation, pooling 정책을 적용하여 데이터 수집 안정성 개선

**Prefect 기반 데이터 Workflow Orchestration 구축**
- Prefect 기반 데이터 파이프라인 orchestration 환경을 구축하고 일·주·월 단위 데이터 Workflow 자동화
- 데이터 수집, 통합예약·통합수납 생성, 데이터마트, Funnel 및 월마감 보고서 갱신을 하나의 dependency pipeline으로 구성
- 병원/지점, 데이터 기준월, 처리 단계 등을 parameter화하여 부분 실행 및 과거 데이터 재처리가 가능한 구조 설계
- 업무 특성에 따라 Work Pool을 분리하고 파이프라인 failure/crash notification 및 운영 알림 체계 구축

**데이터 품질 검증 및 데이터마트 구축**
- CRM·MSSQL 원천 데이터, PostgreSQL 통합 데이터 및 경영 보고 데이터 간 매출 정합성을 자동 검증하는 reconciliation pipeline 구축
- 병원별 과세·해외매출·수술매출 등 서로 다른 비즈니스 규칙을 데이터 변환 및 검증 로직으로 구현
- 통합 예약·수납 데이터를 기반으로 고객 전환율, 상담, 매출, 객단가 및 KPI 분석용 데이터마트 구축
- Funnel, KPI, 월마감 및 BI용 데이터셋을 자동 생성하여 PostgreSQL 및 Google Sheets 기반 downstream 분석·리포팅 환경 제공
